Layar sentuh & progres

Gunakan tombol arah dan lompat di game. Buka Tas untuk memilih item, lalu tap tile untuk menanam atau memasang. Tahan tile untuk memukul berulang.

Progres disimpan di browser ini melalui menu game. Data tidak tersinkron ke perangkat lain; menghapus data situs juga menghapus simpanan.
